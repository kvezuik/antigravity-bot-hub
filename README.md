# ⚡ Antigravity 2.0 • Grok Bot Studio

> **Мощная графическая десктоп-студия и агент-хаб для Antigravity 2.0 в стиле Grok (xAI)**  
> *Интерфейс Antigravity 2.0 + Grok Chat Canvas, проверка Google-аккаунта и подписки, глубокие рассуждения модели (Reasoning Process) без шаблонных заготовок.*  
> *Ядро: агентный движок [`wallentx/antigravity-cli-termux`](https://github.com/wallentx/antigravity-cli-termux) / Google Antigravity.*

---

## 🌟 Возможности

1. 🖥️ **Десктопный интерфейс Antigravity 2.0 + Grok:**
   - Полноценное графическое приложение (без терминала) со стилем Antigravity 2.0 и неоновым кибер-дизайном Grok.
   - Боковая панель: переключение ботов, статус аккаунта, выбор моделей (`gemini-3.8-flash-high`, `gemini-3.1-pro-high` и др.), переключатель глубины размышлений (`High ⚡`, `Medium`, `Low`).
   - Chat Canvas: интерактивный чат, сворачиваемый блок хода мыслей модели (**💭 Размышления модели**), подсветка синтаксиса и кнопка копирования кода в один клик.

2. 🔐 **Google Аккаунт и проверка подписки:**
   - Автоматическая валидация активного профиля Google и подписки Google Antigravity / Gemini Advanced.
   - Если вход не выполнен — появляется окно с прямой ссылкой на вход в Google Аккаунт.
   - Если подписка отсутствует — система блокирует вызовы и выдает предупреждение с ссылкой на оформление подписки.

3. 🧠 **Настоящий думающий ИИ (без заготовок):**
   - Прямой вызов моделей через Antigravity CLI (`agy`) с параметрами `--effort high`.
   - Полное отсутствие симулированных / заготовленных ответов: каждое сообщение генерируется реальной нейросетью.

4. 🏴‍☠️ **Кастомные AI-личности Grok:**
   - **Grok Fun (Бунтарь)** — едкий сарказм, острый юмор, отсутствие цензуры и правда без нудных формальностей.
   - **Grok Thinker (Архитектор)** — рассуждения от первых принципов (first-principles), пошаговый анализ.
   - **CyberCoder (Antigravity Hacker)** — чистый системный код, Linux, скрипты, дебаг и архитектура.
   - **Code Roaster (Беспощадная Прожарка)** — высмеивает плохой код и выдает оптимальный рефакторинг.
   - **Конструктор ботов** — создание своей личности прямо в интерфейсе.

## 🚀 Как запускать

### Быстрый запуск из домашней папки:
```bash
# 1. Через лаунчер в корне:
python3 ~/agybots.py

# 2. Или через bash-скрипт:
~/run_agybots.sh

# 3. Или напрямую системной командой:
agybots
```

### Запуск на Windows:
```cmd
REM Запустите батник в проводнике или cmd:
run_agybots.bat
```

### Быстрые команды CLI:
```bash
# Чат напрямую с конкретным ботом без главного меню:
python3 ~/antigravity-bot-hub/main.py --bot grok_fun
python3 ~/antigravity-bot-hub/main.py --bot cyber_coder

# Список всех доступных ботов:
python3 ~/antigravity-bot-hub/main.py --list

# Сразу открыть мастер создания нового бота:
python3 ~/antigravity-bot-hub/main.py --create

# Экспортировать всех ботов в Antigravity Rules (.agents/rules/):
python3 ~/antigravity-bot-hub/main.py --export-all
```

## 💬 Команды внутри чата с ботом

Во время диалога с любым ботом доступны слэш-команды:
- `/emoji <значок>` — мгновенно изменить смайлик бота на лету (например, `/emoji 🔥`).
- `/model <модель>` — сменить модель (например, `/model gemini-3.1-pro-high`).
- `/roast <тема>` — принудительно включить режим жесткой прожарки вопроса.
- `/clear` — очистить контекст диалога.
- `/save` — экспортировать текущий диалог в красивый Markdown-файл.
- `/export` — экспортировать бота в правило `.agents/rules/`.
- `/exit` — вернуться в главное меню.

## 📁 Структура проекта

```
~/antigravity-bot-hub/

├── tui.py               # Кроссплатформенный терминальный интерфейс и обработка клавиш

├── bots.py              # Хранилище ботов (JSON) и управление профилями
├── engine.py            # Движок исполнения через Antigravity CLI (agy)
├── exporter.py          # Экспорт в .agents/rules/ и .sh/.bat скрипты
├── run_agybots.sh       # Скрипт запуска для Linux
├── run_agybots.bat      # Скрипт запуска для Windows
├── data/
│   └── bots.json        # База данных ваших ботов и их настроек
└── history/             # Сохраненные сессии чатов в Markdown
```
