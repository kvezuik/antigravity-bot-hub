# ✦ Antigravity 2.0 • Desktop Studio

> **Современное графическое десктоп-приложение и среда управления AI-проектами для Antigravity 2.0**  
> *Разработано по принципам frontend-design и Magic UI: ретро-сетка, шиммер-эффекты, радар размышлений, геометрические минималистичные иконки.*  
> *Ядро: агентный движок [`wallentx/antigravity-cli-termux`](https://github.com/wallentx/antigravity-cli-termux) / Google Antigravity с проверкой аккаунта Google и подписки Antigravity Pro.*

---

## 🌟 Ключевые возможности

1. 🖥️ **Десктопный интерфейс Antigravity 2.0 (Magic UI & Frontend Design):**
   - **Retro Grid & Radial Spotlight:** глубинная темная тема с ненавязчивой фоновой сеткой и мягкими световыми акцентами.
   - **Shimmer Text & Shimmer Button:** динамический перелив света на фирменном заголовке и кнопке создания диалога.
   - **Thinking Radar:** пульсирующая волна радара при размышлении нейросети над задачей.
   - **Border Beam & Active Glow:** подсветка активных диалогов и проектов.
   - **Кастомная палитра геометрических иконок:** минималистичные векторные символы (`✦`, `⬡`, `⚡`, `◈`, `◬`, `☵`, `⛊`, `⌘`, `❖`, `▲`, `●`, `■`, `⬢`, `⊞`, `∿`, `∞`) и эмодзи рабочего окружения. Возможность ввести любой кастомный символ.

2. 📁 **Проекты и отдельные диалоги (Custom Projects & Chats):**
   - Создание и переключение между независимыми проектами с собственными названиями и иконками.
   - Внутри каждого проекта — независимые диалоги с индивидуальными названиями, иконками и историей сообщений.
   - Возможность переименования, смены значков, экспорта в Markdown и полной очистки контекста.

3. 🔐 **Google Аккаунт и валидация подписки:**
   - Автоматическая проверка активного профиля Google и подписки Google Antigravity Pro (Gemini Advanced).
   - Если вход не выполнен — удобная модальная карточка с прямой ссылкой на авторизацию в Google.
   - Если подписка отсутствует — блокировка вызовов с предупреждением и ссылкой на оформление подписки.

4. 🧠 **Настоящее ядро Antigravity 2.0 (без заготовок):**
   - Прямой вызов моделей через Antigravity CLI (`agy`) с параметрами `--effort high`.
   - Полное отсутствие шаблонных заготовок: каждое сообщение формируется реальной нейросетью с отображением блока рассуждений (**💭 Размышления модели**).
   - Выбор моделей: `Gemini 3.8 Flash (High)`, `Gemini 3.1 Pro (High)`, `Claude Sonnet 4.6`, `GPT-OSS 120B`.

## 🚀 Запуск и установка

### 🐧 Linux (AppImage & Скрипты):
```bash
# 1. Запуск через собранный AppImage:
chmod +x AntigravityBotHub-Linux-x86_64.AppImage
./AntigravityBotHub-Linux-x86_64.AppImage

# 2. Или запуск через системную команду:
agybots

# 3. Или запуск напрямую из исходников:
python3 ~/antigravity-bot-hub/main.py
```

### 🪟 Windows (Portable):
1. Скачайте архив `AntigravityBotHub-Windows-Portable-x64.zip` из раздела [Releases](https://github.com/kvezuik/antigravity-bot-hub/releases).
2. Распакуйте в любую удобную папку.
3. Запустите `run_agybots.bat` или `agybots.exe`.

## 📁 Архитектура проекта

```
~/antigravity-bot-hub/
├── main.py              # Точка входа приложения (запуск GUI Studio или CLI)
├── gui.py               # Встроенный HTTP/REST бэкенд и локальный веб-сервер
├── store.py             # Хранилище проектов, диалогов и историй сообщений
├── engine.py            # Движок исполнения Antigravity CLI (agy) и проверка Google Auth
├── web/
│   ├── index.html       # Интерфейс Antigravity 2.0 Desktop Studio
│   ├── style.css        # Стилистика Magic UI (Retro Grid, Shimmer, Radar)
│   ├── app.js           # Логика управления проектами, диалогами и чатом
│   └── icon.png         # Логотип приложения
├── data/
│   └── store.json       # Локальная база данных проектов и диалогов
├── packaging/
│   └── agybots.desktop  # Интеграция в системное меню Linux
├── run_agybots.sh       # Скрипт запуска для Linux
└── run_agybots.bat      # Скрипт запуска для Windows
```
