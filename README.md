# ⚡ Antigravity Bot Hub (Grok Edition)

> **Мощная студия и менеджер специализированных ИИ-ботов для Antigravity CLI в стиле Grok (xAI)**  
> *Работает нативно и одинаково красиво на Linux и Windows без внешних зависимостей (`pip` не требуется!)*

---

## 🌟 Возможности

1. 🤖 **Специализированные боты для всего:**
   - **🏴‍☠️ Grok Fun (Бунтарь)** — едкий сарказм, острый юмор, отсутствие занудства и правда без цензуры.
   - **🧠 Grok Thinker (Архитектор Мысли)** — рассуждения от первых принципов (first-principles), глубинная логика.
   - **💻 CyberCoder (Antigravity Hacker)** — чистый системный код, скрипты, архитектура и знание Antigravity.
   - **🔥 Code Roaster (Беспощадная Прожарка)** — эпично высмеивает спагетти-код и тут же выдает идеальный рефакторинг.
   - **🚀 Startup 100x (Визионер)** — валидация MVP, поиск ниш, вирусные механики и питчи.
   - **🎓 ELI5 Mentor (На Пальцах)** — объясняет сложнейшие концепции простыми жизненными аналогиями.
   - **🕵️ Bug Hunter (Детектив Систем)** — поиск причин сбоев, анализ трейсов, логов и дампов ядра.
   - **🎨 CyberBard (Мастер Слов)** — креативный копирайтинг, сюжеты, слоганы и сценарии.
   - **➕ Конструктор любых ботов** — пошаговый мастер создания бота под любую вашу задачу.

2. 🎨 **Кастомизация смайликов и аватаров:**
   - **Тематические коллекции:** Grok Rebel (`🏴‍☠️`, `🤪`, `😈`, `🔥`), Cyberpunk (`🤖`, `💻`, `⚡`), Deep Mind (`🧠`, `🦉`, `💡`), Creative (`🎨`, `🦄`, `✨`), DevOps (`🛡️`, `🐧`, `🐳`), Gaming (`🎮`, `🐉`), ASCII/Cyber-бейджи (`[✦]`, `[⚡]`, `(¬_¬)`).
   - **Свои смайлики:** можно вписать абсолютно любой эмодзи или текстовый значок с клавиатуры.
   - **Динамические настроения (Moods):** отдельные смайлики для ожидания, анализа задачи, печати и завершения ответа.
   - **Стили рамок:** Boxed `[ 🏴‍☠️ Grok ]`, Neon `✦ 🏴‍☠️ Grok »`, Cyber `⟦ 🏴‍☠️ Grok ⟧`, Bubble `( 🏴‍☠️ Grok )`.

3. 🖥️ **Красивое меню под Linux и Windows:**
   - Неоновая 256-цветовая палитра и рамки со скругленными углами (`╭───╮`).
   - Навигация стрелочками (`↑`/`↓` + `Enter`) или быстрыми цифрами (`1`..`9`).
   - Автоматическая инициализация ANSI VT100 на Windows и Linux.

4. 🚀 **Бесшовная интеграция с Antigravity:**
   - Прямой вызов моделей через Antigravity CLI (`agy`).
   - Экспорт любого бота в системные правила `.agents/rules/persona_<name>.md`.
   - Генерация одиночных скриптов запуска `.sh` и `.bat`.

## 🚀 Как запускать

### Быстрый запуск из домашней папки:
```bash
# 1. Через лаунчер в корне:
python3 ~/agybots.py

# 2. Или через bash-скрипт:
~/run_agybots.sh

# 3. Или напрямую системной командой:
agybots
```

### Запуск на Windows:
```cmd
REM Запустите батник в проводнике или cmd:
run_agybots.bat
```

### Быстрые команды CLI:
```bash
# Чат напрямую с конкретным ботом без главного меню:
python3 ~/antigravity-bot-hub/main.py --bot grok_fun
python3 ~/antigravity-bot-hub/main.py --bot cyber_coder

# Список всех доступных ботов:
python3 ~/antigravity-bot-hub/main.py --list

# Сразу открыть мастер создания нового бота:
python3 ~/antigravity-bot-hub/main.py --create

# Экспортировать всех ботов в Antigravity Rules (.agents/rules/):
python3 ~/antigravity-bot-hub/main.py --export-all
```

## 💬 Команды внутри чата с ботом

Во время диалога с любым ботом доступны слэш-команды:
- `/emoji <значок>` — мгновенно изменить смайлик бота на лету (например, `/emoji 🔥`).
- `/model <модель>` — сменить модель (например, `/model gemini-3.1-pro-high`).
- `/roast <тема>` — принудительно включить режим жесткой прожарки вопроса.
- `/clear` — очистить контекст диалога.
- `/save` — экспортировать текущий диалог в красивый Markdown-файл.
- `/export` — экспортировать бота в правило `.agents/rules/`.
- `/exit` — вернуться в главное меню.

## 📁 Структура проекта

```
~/antigravity-bot-hub/
├── main.py              # Основное приложение и интерактивное меню
├── tui.py               # Кроссплатформенный терминальный интерфейс и обработка клавиш
├── emojis.py            # Наборы смайликов, пресеты настроений и стили рамок
├── bots.py              # Хранилище ботов (JSON) и управление профилями
├── engine.py            # Движок исполнения через Antigravity CLI (agy)
├── exporter.py          # Экспорт в .agents/rules/ и .sh/.bat скрипты
├── run_agybots.sh       # Скрипт запуска для Linux
├── run_agybots.bat      # Скрипт запуска для Windows
├── data/
│   └── bots.json        # База данных ваших ботов и их настроек
└── history/             # Сохраненные сессии чатов в Markdown
```
